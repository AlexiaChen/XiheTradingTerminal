## [0.0.1] - 2026-02-12

- Initial public release.
- Added TradingView sidebar chart webview.
- Added multi-tab chart workspace with per-tab symbol, interval, studies, and theme.
- Added collapsible settings header with toggle in the tabs row.
- Added workspace persistence for tabs and UI state.
- Updated custom controls styling to better match TradingView widget visuals.
